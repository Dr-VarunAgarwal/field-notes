Edit captions & tags

Fix a caption, name a street-art artist, tweak a description — one photo at a time, from anywhere. Structural fields (id, image path, category, order, color) aren't editable here; this is for text content only. A new page or a full re-batch still goes through a proper session.

Same token as the story uploader works here too (same repo scope). Create one at github.com/settings/tokens — fine-grained, scoped only to the field-notes repo, with Contents: Read and write permission. Stored only in this browser.
